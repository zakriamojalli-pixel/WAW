# WAW - واو

### مع واو، حياتي واو!

واو تطبيق شامل يهدف إلى جمع الخدمات والأدوات التي يحتاجها المستخدم في مكان واحد.

## المجالات الستة عشر

1. التعليم والمعرفة
2. تنظيم الحياة والوقت
3. إدارة الأموال
4. الصحة والعادات
5. العمل والوظائف
6. التسوق والخدمات
7. الكتب والقراءة
8. المهارات والمواهب
9. الذكاء الاصطناعي
10. الخدمات العائلية والشخصية
11. التعافي
12. الصحة النفسية
13. السفر والتنقل والسياحة
14. المنزل والحياة اليومية
15. الثقافة والترفيه
16. الخدمات الحكومية والقانونية

## التقنيات

- Flutter
- Dart
- Android
- iOS

## اللغات

- العربية
- الإنجليزية

## الرؤية

إنشاء تطبيق متكامل وسهل الاستخدام يجمع الخدمات الرقمية في تجربة واحدة.
